Como se usa

1

Descomprime

tar xzf direkt-portable-linux.tar.gz
cd direkt-portable-linux
2

Juega

./direkt.sh
3

O salta el menu

./direkt.sh jugar
4

Compila un mapa

./direkt.sh bsp mapa.map salida.bsp

Que lleva

  • ironwail — el motor, compilado
  • direkt-bsp — generador de .bsp: lee .map y escribe el BSP de Quake con texturas y luz
  • direkt-edit — editor de niveles con picking, arrastre de caras e historial
  • progs.dat — la logica de juego
  • datos/ — LibreQuake completo
  • fuente/ — todo el codigo, porque el binario es GPL
  • fuente/cache/ — el tarball del motor con su SHA-256, para recompilar sin red
  • docs/ — la documentacion de formatos y de las trampas del motor
  • Makefile — por si prefieres reconstruirlo todo

Lo que hace falta en tu equipo

Nada que compilar. Solo esto:

  • OpenGL 4.3, o 1.5 si tu equipo no llega. El paquete trae dos motores con el mismo juego, los mismos mapas y el mismo progs.dat; solo cambia el dibujado. El lanzador mira lo que anuncia tu tarjeta y elige solo, sin preguntar.
  • SDL2 (libsdl2-2.0-0, libgl1)
  • Si no hay tarjeta grafica: Mesa (libgl1-mesa-dri), que dibuja por software. El lanzador recurre ahi solo cuando detecta que el OpenGL de la maquina no llega, y entonces usa ademas el motor ligero, que es mas rapido por software que el otro.
  • Opcional: xvfb para la comprobacion automatica, imagemagick para las capturas

En macOS el motor principal no llega: el OpenGL del sistema se queda en 4.1 y no hay forma de subirlo. Ahi el lanzador usa el motor ligero, que con 4.1 si funciona, ademas del generador de mapas y el editor.

En Debian y Ubuntu: sudo apt install libsdl2-2.0-0 libgl1 libgl1-mesa-dri xvfb

El menu

Al descomprimir y abrir el paquete aparece una ventana con un lateral y cuatro entradas: Jugar, Minijuego, Descargas y Salir. Desde ahi se juega, se mira si hay una release nueva y se echapuera un rato al minijuego de pulsar botones.

El menu esta hecho en Python con tkinter, que ya viene en la mayoria de las instalaciones. Y no hace falta: si no esta, el lanzador lo avisa y entra al juego igualmente. Para entrar sin menu:

./direkt.sh jugar

Lo unico imprescindible para jugar es el motor, que ya va dentro del paquete.

Todos los comandos

  • ./direkt.sh — abrir el menu
  • ./direkt.sh jugar — jugar sin pasar por el menu
  • ./direkt.sh menu — abrir solo el menu
  • ./direkt.sh test — comprobar que el paquete arranca de verdad
  • ./direkt.sh editor — abrir el editor de niveles
  • ./direkt.sh bsp a b — compilar el mapa a en b.bsp
  • ./direkt.sh shell — una shell con los binarios en el PATH
  • ./bin/direkt-bsp --check b.bsp — validar un .bsp
