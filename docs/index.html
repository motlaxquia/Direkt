Como se usa

1

Descomprime

tar xzf direkt-portable-linux.tar.gz
cd direkt-portable-linux
2

Juega

./direkt.sh
3

Compila un mapa

./direkt.sh bsp mapa.map salida.bsp

Que lleva

  • ironwail — el motor, compilado
  • direkt-bsp — generador de .bsp: lee .map y escribe el BSP de Quake con texturas y luz
  • direkt-edit — editor de niveles con picking, arrastre de caras e historial
  • progs.dat — la logica de juego
  • datos/ — LibreQuake completo
  • fuente/ — todo el codigo, porque el binario es GPL
  • fuente/cache/ — el tarball del motor con su SHA-256, para recompilar sin red
  • docs/ — la documentacion de formatos y de las trampas del motor
  • Makefile — por si prefieres reconstruirlo todo

Lo que hace falta en tu equipo

Nada que compilar. Solo esto:

  • OpenGL 4.3. El motor usa compute shaders para dibujar el mundo, y por eso pide esa version y no una anterior. Con una tarjeta grafica de los ultimos diez años esto se cumple solo.
  • SDL2 (libsdl2-2.0-0, libgl1)
  • Para jugar sin tarjeta grafica: Mesa (libgl1-mesa-dri), que dibuja por software. El lanzador cae ahi solo cuando detecta que el OpenGL de la maquina no llega.
  • Opcional: xvfb para la comprobacion automatica, imagemagick para las capturas

En macOS esto no se cumple: el OpenGL del sistema llega como mucho a 4.1 y no hay forma de subirlo. El paquete se publica para probarlo, pero en un Mac con GPU de Apple el motor probablemente no arrancara. El generador de mapas y el editor si que funcionan.

En Debian y Ubuntu: sudo apt install libsdl2-2.0-0 libgl1 libgl1-mesa-dri xvfb

Todos los comandos

  • ./direkt.sh — jugar
  • ./direkt.sh test — comprobar que el paquete arranca de verdad
  • ./direkt.sh editor — abrir el editor de niveles
  • ./direkt.sh bsp a b — compilar el mapa a en b.bsp
  • ./direkt.sh shell — una shell con los binarios en el PATH
  • ./bin/direkt-bsp --check b.bsp — validar un .bsp
